# TakeStart

Сервис витрин для малого бизнеса: продавец ведёт каталог, покупатель собирает корзину, заказ передаётся продавцу через WhatsApp.

## Language

**Shop**:
Магазин или меню кафе продавца с уникальным slug, одним WhatsApp-номером и режимом получения.
_Avoid_: Store, Menu, Точка

**Seller**:
Владелец магазинов, входит через Google или email. Один аккаунт владеет N магазинами.
_Avoid_: Merchant, Владелец, Админ

**Buyer**:
Анонимный покупатель без аккаунта, открывает витрину по ссылке из WhatsApp/QR.
_Avoid_: User, Client, Customer

**Category**:
Обязательная группировка товаров внутри Shop для навигации по меню.
_Avoid_: Group, Раздел

**Product**:
Позиция каталога с ценой в тиынах и флагом наличия. Вариантов (размер/добавки) в MVP нет.
_Avoid_: Item, Dish, Товар (в коде — Product)

**Cart**:
Временное состояние покупателя в браузере (Context + localStorage), ещё не заказ.
_Avoid_: Basket

**Order**:
Снапшот корзины, сохранённый в БД со статусом `new` в момент нажатия «Заказать в WhatsApp», даже если отправка в WA не завершена.
_Avoid_: Purchase, Transaction, Заявка

**WhatsApp Handoff**:
Редирект покупателя на `wa.me/<номер магазина>?text=<чек заказа>` с дублирующими кнопками «открыть ещё раз / скопировать».
_Avoid_: Отправка заказа, Checkout complete

**Fulfillment Mode**:
Режим Shop: `delivery` (адрес обязателен), `pickup` (самовывоз/за столом, адреса нет) или `both` (выбор на checkout).
_Avoid_: Delivery type, Shipping
