# TakeStart — дизайн «Чековая лента»

Витрины малого бизнеса: продавец ведёт каталог, покупатель собирает корзину,
заказ уходит продавцу через WhatsApp как чек.

## Замысел

- Предмет: чек заказа. Он уже есть в домене: снапшот корзины и текст
  `wa.me/<номер>?text=<чек>`. Дизайн строится от него, а не от «карточек SaaS».
- Покупатель: аноним, открывает витрину с телефона по ссылке из WhatsApp или QR.
  Держит телефон одной рукой, решает быстро.
- Работа страницы: помочь выбрать за минуту и аккуратно передать заказ в чат.
- Продавец: владелец маленького кафе или лавки, ведёт каталог с телефона.
  Кабинет говорит на том же визуальном языке, что и витрина.

## Цвет

Шесть именованных значений. Холодная бумага вместо тёплого крема,
хвойные чернила вместо нейтрального zinc, один острый акцент на цены.

| Токен     | Hex     | Роль                                                        |
| --------- | ------- | ----------------------------------------------------------- |
| `paper`   | #FFFFFF | Бумага чека, фон ленты                                      |
| `fog`     | #E9EFE7 | Эвкалиптовая подложка вокруг ленты, спокойный холодный фон  |
| `ink`     | #20382C | Хвойные чернила: основной текст, шапки, контурные кнопки    |
| `leaf`    | #14663B | Глубокий лист WhatsApp: только финальный CTA передачи заказа |
| `tandoor` | #B3271E | Перечная печать: цены, активная категория, стоп-лист        |
| `tag`     | #FFC53D | Базарный ценник: подсветка итоговой суммы, ничего больше    |

Производные: `fog-deep` #DDE7DA, `ink-soft` #4A5F53, `ink-faint` #7D8F84,
`line` #D8E0D5 (линейки и точечные лидеры), `leaf-deep` #0E4D2C (нажатие CTA).

## Типографика

Два семейства, оба с родной кириллицей (ru/kk/en). Роли не пересекаются.

- Акцидентный: Unbounded 500–700. Название магазина, итоги, заголовок главной.
  Кегль 20–28, трекинг −0.02em, интерлиньяж 1.05. Только короткие строки.
- Текстовый: Golos Text 400–700. Описания, формы, чеки, кабинет.
  Кегль 15–16, интерлиньяж 1.55, длина строки до 60 знаков, выключка влево.

Мелкая учётная мета (адрес, доставка, состав чека) — Golos 13, цвет `ink-faint`,
строчными, через запятые. Без капса, без моноширинных подписей.

## Раскладка

Одна колонка-лента `max-w-xl` по центру подложки `fog`. Всё выравнивается влево:
покупатель сканирует список сверху вниз одним пальцем.

```
┌ эвкалиптовая подложка ─────────────────┐
│ ┌─ бумажная лента ───────────────────┐ │
│ │ НАЗВАНИЕ ЛАВКИ (Unbounded)  RU KZ EN│ │
│ │ адрес, доставка от 800 ₸            │ │
│ │ Супы___ Горячее  Выпечка (подчёрк.) │ │
│ │ ─────────────────────────────────── │ │
│ │ [фото] Лагман ········ 1 900 ₸  [+] │ │
│ │        говядина, лук                │ │
│ │ [фото] Манты ········· 2 400 ₸ [−2+]│ │
│ │ ─ ─ ─ перфорация ─ ─ ─ ─ ─ ─ ─ ─ ─  │ │
│ │ 3 в корзине · 6 200 ₸  [Оформить]   │ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

Оформление заказа — та же лента как незаполненный бланк: поля без обводок-пилюль,
подпись суммы штампом `tag`, одна кнопка `leaf` «Заказать в WhatsApp».
Успех — пробитый чек: перфорация сверху и снизу, блок чека моноширинным не
набирается, это обычный Golos 13/1.6, чтобы чек читался как в чате.
Кабинет продавца — та же лента, только шире: список магазинов и заказы идут
строками гроссбуха, а не карточками.

## Принципы

Запоминается один приём: чековая бухгалтерия — точечные лидеры между названием
и ценой, зигзаг перфорации, сумма-штамп на жёлтом ценнике. Всё остальное тихое:
радиусы не больше 8px, без теней, без градиентов, без иконок-эмодзи в интерфейсе.

## Что отклонили и почему

- Тёплый крем #F4F1EA с терракотой: уют кофейни, а у нас базарный прилавок
  и холодный свет экрана. Взяли эвкалипт `fog` и хвою `ink`.
- Тёмная тема с кислотным акцентом: витрину открывают днём на солнце,
  контраст нужен на белой бумаге, а не на чёрном.
- Газетная сетка с волосяными линейками: контент не статья, а список выбора.
  Линейки есть, но одна вертикальная логика — лента.
- SaaS-набор: одинаковые скруглённые карточки с тенью и пилюли категорий.
  Товары стали строками с лидерами, категории — подчёркиваемыми вкладками.
- Шаблонный хром: капс-подписи, мета через «·», стрелки «→», моно-подписи.
  Мета пишется предложениями через запятые, языки — компактным сегментом.

## Карта внедрения (apps/web)

- `app/globals.css` — токены `@theme`, классы `ts-tape`, `ts-leader`,
  `ts-zigzag-top/bottom`, `ts-stamp`, `ts-tab`, `ts-enter`.
- `app/layout.tsx` — шрифты Unbounded + Golos Text через `next/font`.
- `app/[locale]/page.tsx` — главная как вывеска лавки на `fog`.
- `app/[locale]/s/[slug]/page.tsx` — лента витрины, вкладки категорий.
- `components/storefront/product-card.tsx` — строка гроссбуха с лидером цены.
- `components/storefront/cart-bar.tsx` — корешок чека с перфорацией.
- `components/storefront/checkout-form.tsx` — бланк чека, итог-штамп.
- `app/[locale]/s/[slug]/checkout/success/page.tsx` — пробитый чек.
- `components/storefront/locale-switcher.tsx` — языковой сегмент без пилюль.
- `app/[locale]/login/page.tsx`, `app/[locale]/dashboard/**` — кабинет
  в том же языке: строки вместо карточек, один `leaf`-CTA на действие.

## Сдержанность и доступность

- Одно движение на сценарий: лента поднимается один раз при загрузке,
  корешок корзины выезжает только при изменении состава.
- `prefers-reduced-motion` гасит всё движение.
- Фокус виден везде: обводка `ink` 2.5px.
- Контраст: `ink` на `paper` и белый на `leaf` держат текст 13px и крупнее.
- До 360px лента занимает всю ширину, фото товаров 64px, степпер не меньше 44px.
