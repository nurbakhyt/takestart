# Заказ создаётся в БД до отправки в WhatsApp

Заказ со статусом `new` сохраняется в момент нажатия «Заказать в WhatsApp», а не после возврата из WA. Иначе брошенные переходы (покупатель не завершил отправку) теряются и у продавца нет аналитики. Компромисс: возможны «пустые» заказы без сообщения в WA — продавец закрывает их статусом `cancelled`.
