# Next.js + Cloudflare Pages + D1 + R2

Малому бизнесу нужна дешёвая edge-витрина с минимумом операционки. Выбрали Next.js App Router на Cloudflare Pages (через next-on-pages), D1 для всех сущностей, R2 для фото товаров. Альтернативы (Supabase/Neon + Vercel) отвергнуты: лишний вендор и счёт при том же объёме МСБ-трафика.
