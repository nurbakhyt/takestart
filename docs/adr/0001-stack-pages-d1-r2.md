# Next.js + Cloudflare Pages + D1 + R2

Малому бизнесу нужна дешёвая edge-витрина с минимумом операционки. Выбрали Next.js App Router на Cloudflare Pages (через next-on-pages), D1 для всех сущностей, R2 для фото товаров. Альтернативы (Supabase/Neon + Vercel) отвергнуты: лишний вендор и счёт при том же объёме МСБ-трафика.

**Статус:** платформа из этого ADR не реализована. `next-on-pages` не появился ни в
одном коммите, а код с первой сборки (`3140d1a` → `a6e4b37`) разворачивается
воркером Cloudflare через OpenNext — см. [ADR-0003](0003-workers-opennext.md).
Выбор стека (Next.js App Router, D1 для всех сущностей, R2 для фото) остаётся
в силе, заменена только платформа деплоя.
